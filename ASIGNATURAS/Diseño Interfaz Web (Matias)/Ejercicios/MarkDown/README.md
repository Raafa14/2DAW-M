### Trozo de codigo de un button (dentro del body), de ejemplo:

```
<body>

    <h1>¡Hola, mundo!</h1>

    <p>
        Este es un fragmento de código HTML básico para empezar.
    </p>

    <button onclick="alert('¡Hiciste clic!')">
        Haz clic aquí
    </button>

</body>
```
